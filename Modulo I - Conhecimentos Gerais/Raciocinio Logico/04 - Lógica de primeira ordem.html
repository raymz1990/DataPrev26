01

Objetivos de aprendizagem

Ao final deste estudo, o(a) candidato(a) deverá ser capaz de:

  • Compreender a diferença entre a lógica sentencial (trata proposições como blocos indivisíveis) e a lógica de primeira ordem (analisa a estrutura interna das proposições, com sujeitos e predicados).
  • Reconhecer e empregar os quantificadores universal (∀) e existencial (∃).
  • Identificar predicados e termos (constantes e variáveis) em proposições categóricas.
  • Negar corretamente proposições quantificadas, aplicando a relação entre ∀ e ∃ na negação.
  • Traduzir frases da linguagem natural para a notação de lógica de primeira ordem e vice-versa.
  • Resolver questões FGV que exigem interpretação correta de "todo", "algum", "nenhum" e suas negações em contextos institucionais.
02

Resumo executivo

A lógica de primeira ordem (também chamada lógica de predicados) vai além da lógica sentencial: em vez de tratar cada proposição como um bloco indivisível (P, Q, R), ela analisa a estrutura interna das proposições, distinguindo o sujeito (termo) do predicado (propriedade atribuída ao sujeito). Isso permite expressar formalmente afirmações como "todo servidor é responsável" ou "algum funcionário fala inglês", que a lógica sentencial não consegue capturar com precisão.

Os dois quantificadores centrais são o universal (∀), lido como "para todo" ou "qualquer que seja", e o existencial (∃), lido como "existe pelo menos um" ou "algum". Uma proposição como "Todo servidor é responsável" é simbolizada como ∀x (Servidor(x) → Responsável(x)); "Algum servidor fala inglês" é simbolizada como ∃x (Servidor(x) ∧ FalaInglês(x)).

A negação de proposições quantificadas segue uma regra de "espelho": a negação de "todo x é P" é "existe x que não é P" (¬∀x P(x) ≡ ∃x ¬P(x)), e a negação de "existe x que é P" é "todo x não é P" (¬∃x P(x) ≡ ∀x ¬P(x)). Essa relação de dualidade entre ∀ e ∃ é o ponto mais cobrado do tópico em concursos.

É importante notar que "Todo A é B" NÃO é simbolizado com conjunção (∧), mas com condicional (∀x (A(x)→B(x))); já "Algum A é B" É simbolizado com conjunção (∃x (A(x)∧B(x))) — essa troca de conectivo entre universal e existencial é uma armadilha estrutural clássica.

04

Explicação completa

4.1 Da lógica sentencial à lógica de primeira ordem

Na lógica sentencial, "Todo servidor é responsável" seria tratada como uma proposição atômica única (P), sem estrutura interna analisável. A lógica de primeira ordem "abre" essa proposição, identificando um predicado (Responsável) aplicado a um termo (servidor), quantificado universalmente.

ElementoDefiniçãoExemplo
Termo (constante)Nome específico de um indivíduo"João", "a", em Responsável(João)
Termo (variável)Representa um indivíduo genérico, indeterminado"x", em Servidor(x)
PredicadoPropriedade ou relação atribuída ao(s) termo(s)Servidor(x), Responsável(x), MaiorQue(x,y)
Quantificador universal (∀)"Para todo x"∀x (algo é verdade para todo x)
Quantificador existencial (∃)"Existe pelo menos um x"∃x (algo é verdade para pelo menos um x)

4.2 Simbolização de proposições categóricas

Frase em portuguêsSimbolização em lógica de primeira ordem
Todo A é B∀x (A(x) → B(x))
Algum A é B∃x (A(x) ∧ B(x))
Nenhum A é B∀x (A(x) → ¬B(x)) — ou ¬∃x (A(x) ∧ B(x))
Algum A não é B∃x (A(x) ∧ ¬B(x))
⚠ Pegadinha clássica FGV: conectivo trocado no universal

O erro mais comum é simbolizar "Todo servidor é responsável" com conjunção: ∀x (Servidor(x) ∧ Responsável(x)) — isso está errado, pois afirmaria que "para todo x, x é servidor E x é responsável", implicando que TUDO no universo é servidor. A forma correta usa condicional: ∀x (Servidor(x) → Responsável(x)), que afirma "se x é servidor, então x é responsável" — deixando aberto que existam x's que não são servidores.

4.3 Negação de proposições quantificadas (dualidade ∀/∃)

Proposição originalNegação (regra de dualidade)
∀x P(x) ("todo x é P")∃x ¬P(x) ("existe x que não é P")
∃x P(x) ("existe x que é P")∀x ¬P(x) ("todo x não é P" / "nenhum x é P")
Todo A é BAlgum A não é B
Algum A é BNenhum A é B
Nenhum A é BAlgum A é B
Algum A não é BTodo A é B
✅ Macete da dualidade ∀/∃

Para negar uma proposição quantificada: (1) troque ∀ por ∃ (ou vice-versa); (2) negue o predicado interno. Isso vale tanto na notação simbólica quanto na linguagem natural: negar "todo" vira "algum... não"; negar "algum" vira "nenhum".

4.4 Predicados com múltiplos termos (relações)

Predicados podem envolver mais de um termo, expressando relações entre indivíduos: MaiorQue(x, y) significa "x é maior que y"; Subordinado(x, y) significa "x é subordinado de y".

📘 Exemplo aplicado

"Todo analista tem um supervisor" pode ser simbolizado como: ∀x (Analista(x) → ∃y Supervisor(y, x)) — "para todo x, se x é analista, então existe y tal que y é supervisor de x". Combina os dois quantificadores em uma única proposição, técnica avançada, mas ocasionalmente cobrada.

4.5 Tradução entre linguagem natural e notação simbólica

Linguagem naturalNotação simbólica
"Todos os servidores públicos seguem o código de ética."∀x (Servidor(x) → SegueÉtica(x))
"Existe um analista que não concluiu o curso."∃x (Analista(x) ∧ ¬ConcluiuCurso(x))
"Nenhum funcionário terceirizado tem acesso ao sistema restrito."∀x (Terceirizado(x) → ¬TemAcesso(x))
"Alguns gestores participaram do treinamento."∃x (Gestor(x) ∧ ParticipouTreinamento(x))
🏛 Estilo FGV

A FGV raramente exige que o candidato escreva a notação simbólica completa; o mais comum é apresentar uma proposição categórica em português e pedir sua negação correta em português, testando o domínio da regra de dualidade sem exigir simbolização formal explícita — mas o raciocínio subjacente é exatamente o da lógica de primeira ordem.

05

Como a FGV cobra este assunto

Perfil da banca

A FGV apresenta afirmações categóricas envolvendo "todo", "algum", "nenhum" em contexto institucional, pedindo a identificação da negação correta ou a avaliação de uma conclusão a partir de premissas quantificadas.

Forma de cobrança e nível de dificuldade

  • "Assinale a alternativa que apresenta a negação correta da afirmação: 'Todos os servidores...'"
  • "Considerando as premissas quantificadas acima, é correto concluir que..."
  • Ocasionalmente, questões que pedem a simbolização correta em notação de primeira ordem.
  • Dificuldade alta — a armadilha da troca de conectivo (∧ x →) é sutil e frequentemente ignorada por candidatos.

Assuntos favoritos da banca

Assunto favoritoFrequência
Negação de "todo" e "algum" (dualidade ∀/∃)Muito alta
Simbolização correta de "todo A é B" com condicionalAlta
Conclusões a partir de premissas categóricas combinadasAlta
Predicados com relações (dois termos)Baixa-média

Pegadinhas recorrentes

  1. Simbolizar "todo A é B" com conjunção (∧) em vez de condicional (→).
  2. Negar "todo" como "nenhum" em vez de "algum... não".
  3. Negar "algum" como "algum não" em vez de "nenhum".
  4. Confundir a ordem dos termos em predicados relacionais (MaiorQue(x,y) ≠ MaiorQue(y,x)).

Casos reais de cobrança (padrão observado em provas FGV)

📄 Padrão observado

É comum a FGV usar afirmações sobre categorias de servidores, cargos ou processos institucionais ("Todo processo revisado pela auditoria recebe selo") para testar a negação correta, sempre em linguagem natural, mas exigindo raciocínio de primeira ordem subjacente.

Sinais de alerta durante a prova

  • Ao negar "todo", pense "basta UM contraexemplo" — a negação vira "algum... não".
  • Ao negar "algum", pense "teria que não haver NENHUM caso" — a negação vira "nenhum".
  • Nunca simbolize "todo A é B" com "e" (∧) — sempre use "se... então" (→).
06

Decore para a prova

🧠 Mnemônico UNIVERSAL = CONDICIONAL, EXISTENCIAL = CONJUNÇÃO

"Todo" (∀) sempre acompanha "→" (se... então). "Algum" (∃) sempre acompanha "∧" (e).

🧠 Tabela mental de negação categórica

Todo ↔ Algum...não. Algum ↔ Nenhum. (São pares que se negam mutuamente, em "cruz".)

🧠 Macete do contraexemplo

Para derrubar "todo A é B", basta UM A que não seja B. Para derrubar "algum A é B", é preciso que NENHUM A seja B.

07

Resumo para revisão de 5 minutos

  • Lógica de primeira ordem analisa a estrutura interna das proposições: termos + predicados + quantificadores.
  • ∀ = "para todo"; ∃ = "existe pelo menos um".
  • "Todo A é B" → ∀x (A(x)→B(x)) — usa CONDICIONAL, nunca conjunção.
  • "Algum A é B" → ∃x (A(x)∧B(x)) — usa CONJUNÇÃO.
  • Negação de ∀x P(x) é ∃x ¬P(x); negação de ∃x P(x) é ∀x ¬P(x).
  • Negação de "todo A é B" é "algum A não é B"; negação de "algum A é B" é "nenhum A é B".

    Curiosidades

    🎓 Sobre a FGV

    Embora raramente exija notação simbólica explícita, a FGV testa consistentemente o raciocínio de primeira ordem "disfarçado" em linguagem natural, especialmente em normas institucionais que usam "todo", "nenhum" e "algum".

    📚 Curiosidade histórica

    A lógica de primeira ordem foi desenvolvida principalmente por Gottlob Frege no final do século XIX, sendo posteriormente refinada por Bertrand Russell e outros — revolucionou a lógica ao permitir análise da estrutura interna das proposições, algo que a lógica aristotélica tradicional só fazia de forma limitada.

    🔬 Curiosidade acadêmica

    A lógica de primeira ordem é a base formal usada em bancos de dados relacionais e em linguagens de consulta como SQL — a cláusula "EXISTS" em SQL corresponde diretamente ao quantificador existencial ∃, e "FOR ALL" (menos comum) ao quantificador universal ∀.
