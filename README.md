# DataPrev26 — Biblioteca de Estudos (Perfil 10 · Gestão Econômico-Financeira · FGV)

Biblioteca de estudos **100% offline** para o Concurso DATAPREV 2026 (Edital 001/2026),
cargo de Analista de Tecnologia da Informação — **Perfil 10: Gestão Econômico-Financeira**, banca **FGV**.

## Como usar

- Hospedado via **GitHub Pages**: basta abrir o `index.html` (hub) e navegar.
- Também funciona **offline**: baixe o repositório e abra o `index.html` no navegador.
- Nenhuma dependência externa: sem CDN, sem frameworks. Cada página de tópico é um
  arquivo HTML único e autocontido.
- O progresso (checkboxes, checklists, simulados) é salvo em `localStorage` do navegador.

## Estrutura

```
index.html                          → Hub: árvore do edital, busca, filtros e progresso
Modulo I - Conhecimentos Gerais/    → Língua Portuguesa, Inglesa, Raciocínio Lógico,
                                      Atualidades e IA, Legislação (SI e Proteção de Dados)
Modulo II - Conhecimentos Especificos/
  Administracao Financeira/         → Tópicos 01–10 do edital
  (demais matérias do Perfil 10 a caminho)
```

## Padrão de cada página de tópico

- Navbar fixa com breadcrumb (`Início › Módulo › Matéria › Tópico`) e seletor de tópicos da matéria;
- 19 seções fixas: objetivos, resumo executivo, mapa mental, explicação completa, como a FGV cobra,
  decore, revisão de 5 minutos, flashcards (20), questões comentadas (20), mini simulado (30 questões
  com timer e correção automática), checklist, erros comuns, fórmulas, tabelas-resumo, glossário,
  curiosidades, ligações com outros tópicos, plano de revisão e referências;
- Modo claro/escuro, sumário lateral (TOC), busca no conteúdo (Ctrl+K), barra de progresso de leitura
  e botão "voltar ao topo".
